# Halit Çetin

Principal Systems & Software Engineer · 10+ years

I build across every layer of a system: real-time firmware on the microcontroller, the service that collects its telemetry, and the interface an operator actually uses. Most of that work has been in domains where a defect is not a ticket — automotive, aerospace, railway, defense and industrial automation — under ISO 26262, DO-178C, EN 50128 and IEC 61508 up to SIL 4.

Currently leading the embedded, sensor and test infrastructure team at InfoDif.

## What I work on

**Embedded and real-time** — STM32, ESP32, TI TMS570, ARM Cortex-A, Raspberry Pi. FreeRTOS, SafeRTOS, VxWorks, Zephyr, PREEMPT_RT, Yocto, Buildroot. BLDC and DC motor control.

**Signals and sensing** — Acoustic and radar DSP: detection, tracking, classification. STFT, MFCC, TDOA, beamforming. GPS/IMU fusion and autonomous positioning. FPGA-side embedded software.

**Communication and integration** — CAN, MIL-STD-1553, EtherCAT, Profinet, Profibus DP, Modbus RTU/TCP, MVB, RS-485, BLE 5.0. SCADA, PLC, HMI, OPC UA, MES and ERP integration. SAPIENT and STANAG 4817.

**Systems above the firmware** — C, C++, C#, Python, TypeScript. ASP.NET Core, NestJS, FastAPI, React, Next.js, Angular. Qt/QML, WPF, .NET MAUI, React Native. PostgreSQL, MongoDB, Redis, InfluxDB, Kafka, RabbitMQ, Docker.

**AI at the edge and on-premise** — Air-gapped LLM deployments, multimodal semantic search with Qdrant, RAG. OpenCV, ANPR, TinyML.

**Verification** — MISRA C/C++, AUTOSAR, ASPICE, ERTMS/ETCS. Cantata, Tessy, Trace32, Vector CANoe/CANalyzer, dSPACE HIL, PXI ATE.
